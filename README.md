✨ Features

🔐 Login System

User authentication with database validation

👤 Customer Information

Name

Email

Phone number

🎟️ Seat Selection System

🟩 Green seats → Captured / Booked

⬜ White seats → Available

Seat status stored in the database

🍿 Snack Selection

Cola

Popcorn

Chocolate

Quantity control using (+ / −)

💰 Automatic Price Calculation

🗄️ Database Integration

Tickets information saved

Captured seats stored and reloaded

🧾 PDF Ticket Generation

Ticket is generated after saving

PDF is automatically saved to the Desktop

🖨️ Save & Print Ticket

🪟 User-friendly Windows Forms UI

📦 Windows Installer Included

🛠️ Technologies Used

C#

Windows Forms

.NET Framework

SQL Database

ADO.NET

PDF generation library (e.g. iTextSharp)

Visual Studio

🗄️ Database Details

The application uses an SQL database to store:

User login credentials

Customer information

Ticket details

Seat status (captured / available)

Seat colors are dynamically updated based on database values:

Green → Seat already captured

White → Seat available

📄 PDF Ticket

Generated automatically after booking

Contains:

Customer details

Selected seats

Snacks

Total price

Saved directly to the Desktop for easy access

🚀 How to Run the Project

Clone the repository:

git clone https://github.com/ALJAZARIhadi/cinema-windows-forms-app.git


Open the .sln file in Visual Studio

Configure the database connection string

Ensure .NET Framework is installed

Build and run the project
